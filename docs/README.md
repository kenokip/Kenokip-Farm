# Kenokip Farm documentation

Step-by-step guides for setting up and running Kenokip Farm. Start with
**Getting set up**, then pick the features you want to turn on.

> Code comments and error messages refer to these guides by file name
> (for example "see SETUP-B2C.md"). Every guide keeps its original name,
> so you can find it in the lists below.

## Getting set up

| Guide | What it covers |
| --- | --- |

| [SETUP-SECURITY.md](setup/SETUP-SECURITY.md) | Finance portal security: fingerprint/Face unlock, PIN, lockout and alerts, webhook secret |
| [HOW-TO-FARM-SETUP-AND-CROPS.md](guides/HOW-TO-FARM-SETUP-AND-CROPS.md) | The Farm Setup picker, Crops, and Horses |

| [HOW-TO-ADD-OTHER-LIVESTOCK.md](guides/HOW-TO-ADD-OTHER-LIVESTOCK.md) | Dairy cattle, goats & sheep, pigs, rabbits and horses |
